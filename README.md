# 🎯 Xfreme Toolbox

### The Ultimate Windows Optimization Suite

Xfreme Toolbox is a powerful, portable Windows utility that combines 50+ system tweaks, software installers, privacy fixes, and performance optimizations in a single executable.

![Screenshot](https://i.imgur.com/your-screenshot.png)

## ✨ Features

### 🔧 System Tweaks
- Disable Action Center, Cortana, Notifications
- Stop Windows Updates until 2077
- Clear Event Logs & Update Cache
- One-click Windows/Office Activator
- Hibernation, Fastboot, Sleep mode control
- Pagefile (Virtual Memory) management
- Compact OS / LZX compression
- Take Ownership context menu

### 🗑️ UWP & Bloatware Removal
- Microsoft Store
- Xbox Console Companion & Game Bar
- OneDrive
- Cortana
- Phone Link
- Zune Music (Groove)
- Miracast (Connect)

### 📦 Software Installers (Auto-download)
- Chrome, Firefox, Brave, Opera GX
- 7-Zip, WinRAR
- VLC, MPC-HC
- OBS Studio
- HandBrake, Shotcut
- GIMP, ImageGlass
- Visual C++ AIO Redistributables
- DirectX Runtime

### 🎮 Gaming Optimizations
- Game Mode toggle
- Ultimate Performance power plan
- Disable Nagle's Algorithm (reduce ping)
- Hardware Accelerated GPU Scheduling
- Game clients (Steam, Epic, GOG, Ubisoft, Battle.net)

### 🎨 Personalization
- Dark/Light mode switch
- Windows 11 context menu restore
- Disable rounded corners
- Sound enhancements
- CMD color schemes

## 🚀 Quick Start

1. **Download** the latest `XfremeToolbox.exe`
2. **Run as Administrator** (right-click → Run as Admin)
3. **Choose tweaks** from the menu
4. **Enjoy** a faster Windows!

```bash
# Or build from source
git clone https://github.com/XfremeDev/Xfreme-Toolbox.git
cd Xfreme-Toolbox
pip install -r requirements.txt
python main.py
